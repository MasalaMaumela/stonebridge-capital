Stonebridge Capital is a web-based investment platform I developed using Node.js, Express, EJS and MySQL.
Disclaimer this is not a real or registered platform i was just experimenting 
I built this project to provide users with a platform where they can register, manage their accounts, select investment plans, track earnings and participate in a referral programme.

Features
User registration and login.
User dashboard.
Investment plan selection and activation.
Deposit and withdrawal functionality.
Multi-level referral system.
Referral link generation.
Admin dashboard.
MySQL database integration.
Session management and password encryption.
